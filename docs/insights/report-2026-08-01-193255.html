Hooks
Shell commands that auto-run at specific lifecycle events.
Why for you: Bash dominates your usage (1296 calls) and two sessions were derailed by processes grabbing desktop focus — a PreToolUse hook can force headless flags or block foreground launches before they happen.
// .claude/settings.json { "hooks": { "PreToolUse": [{ "matcher": "Bash", "hooks": [{ "type": "command", "command": "grep -Eq '(^|[[:space:]])(godot|blender)([[:space:]]|$)' <<< \"$CLAUDE_TOOL_INPUT\" && ! grep -q -- '--headless\\|xvfb-run' <<< \"$CLAUDE_TOOL_INPUT\" && { echo 'Blocked: launch godot/blender headless or via xvfb-run'; exit 2; }; exit 0" }] }] } }
Custom Skills

For each: land it, or park it with an explicit reason. 2. Verify one journal/chronicle entry exists per merged PR. Backfill any missing; never batch. 3. Run the gate check and paste only pass/fail plus failing test names. 4. Output a report of at most 15 bullet lines. Link to detail, do not paste it. 5. Do NOT declare done until steps 1-3 all report clean.
