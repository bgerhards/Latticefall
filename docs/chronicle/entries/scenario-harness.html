A verification is a document now, not a flag

PRCdecision 064

main.gd had grown twenty-one one-off verification flags because a fixed-frame run has nobody to press a key. A scenario is now a JSON timeline of actions and assertions instead — and building it surfaced a timing fact worth more than the feature: a synthetic press is queued, not delivered on the frame it lands on.

main.gd had accumulated twenty-one one-off verification flags — --paused, --select, --pick, --cursor, --scroll, --build, --speed, --chain, --ability-at, --press-at, and a dozen more — each justified on its own the day it was added, several duplicating each other, and none able to say what should be true once the state was reached. Only how to get there.

A scenario is JSON now: an anchor, a timeline of actions at named frames, and assertions at named frames. Every verb is a thin wrapper over the exact code path its equivalent flag already used — shot, a11y and facings feed main.gd's existing capture code rather than a second copy of it. Assertions are a dotted path into the game's own state export, a comparator, and an optional tolerance, deliberately not an expression evaluator — a verification harness that can run arbitrary expressions is a second language to build and to get wrong.

Two things this made falsifiable that used to be prose

data/tuning.json's ability numbers are assertions rather than a comment nobody re-checks: Overcharge is asserted 12 to 16.2 MW exactly, Shutter's flat add is asserted at +55 MW, and Threshold Surge's falloff is read out of the function that actually computes it and asserted to four decimal places. And a scenario now pins the worst accessibility case on record — anchor-24, 200% interface scale, built, selected and scrolled — with the contrast report taken on the same frame as the screenshot, which is the pairing the analyser has always required and which no flag ever enforced before this. Zero failing, zero warnings, worst contrast 5.75:1.

A timing fact worth more than the feature

Fixing this properly meant routing a synthetic key press through the engine's real input pipeline rather than calling one node's handler directly, so a press can reach whichever node actually owns it — the panel-hide toggle and the tactical map each needed their own boot flag before this, precisely because the old shortcut only ever reached one node. That produced the fact worth recording: the event this way is queued, not delivered inline. An assertion written for the same frame as the press fails; the identical assertion one frame later passes. Measured, then written into the schema, the runner and the dispatcher, so the next person building a scenario does not lose an afternoon rediscovering it.

The twenty-one flags were not deleted in this change — several were the only evidence path for work committed hours earlier, so removing them has to be its own deliberate change rather than quiet attrition. scenarios pass joins the gate at tier 3, measured at about 30 seconds against tier 2's entire 25-second budget, which is exactly why it did not join tier 2 instead.
