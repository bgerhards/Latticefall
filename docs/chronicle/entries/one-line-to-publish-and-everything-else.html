One line publishes it; the other two hundred are what makes that line safe

LFRELdecision 098

The second half of LF-206. release.yml builds the web bundle on a tag, plays it, and pushes it to itch.io with butler — one command, butler push build/web user/game:html5 --userversion X. Everything around it exists because that one command will happily upload a broken bundle with total confidence, and because three of the things that make a bundle broken here are silent.

The previous entry ended at a verified build exists in build/. This is the step that puts it somewhere a person can click, and it is short: butler is itch's official CLI, it takes a directory and a user/game:channel target, and it reads its credential from BUTLER_API_KEY. That last claim was not taken from a guide — v15.30.0 was downloaded and asked.

The archive is also not one file. It carries butler plus 7z.so and libc7zip.so, which have to sit beside it — which is why the workflow extracts the whole thing into one directory on PATH rather than pulling out the binary and wondering later why it cannot open a zip.

Three ways to ship a broken bundle, all of them quiet

Git LFS. 698 files here are LFS-tracked — the two atlas pages the board actually draws from, all the audio, all four fonts. actions/checkout does not fetch LFS by default, and gate.yml's tier-1 job deliberately runs lfs: false because tier 1 never reads a sprite byte. Under that setting every one of those files is a ~130-byte pointer, and Godot will import a pointer-file PNG into some texture and pack it without complaint. The bundle builds green and is visually destroyed. So the release job asserts the smudge actually happened, by looking at the first forty bytes of both atlas pages, before it does anything else.

The import cache. Everywhere else in this repository .godot/ is disposable build output the editor rebuilds on demand — there is a whole rule in CLAUDE.md about never rebuilding it while the owner is playing. At the export boundary that assumption inverts: the export bakes the cache into the pack, so a fresh CI checkout with no cache would export a build whose global class registry is empty. A missing class_name in this engine is a hang, not an error. The workflow imports first, and the tool's verification leg is a play rather than a launch for exactly this reason.

The renderer. GL Compatibility reads back nothing under a truly headless --headless — decision 052, and the reason tools/shot.py exists at all. A bare ubuntu-latest runner could export this game perfectly and be structurally unable to prove the export works. So the release job runs inside the tier-3 container image that already carries a native Linux Godot, xvfb-run and a Mesa software-GL stack, consumed at its stable :tier3 tag rather than rebuilt on the release path.

What a run does when it cannot publish

It publishes nothing, says so in a warning and in the run summary, and attaches the verified bundle to the run as an artifact. It does not fail. That distinction is deliberate and it is the only interesting design decision in the workflow: a release that silently did not publish reads exactly like one that did, and the three things it needs — an itch page whose project kind is set to HTML, an API key, and the user/game slug — are all the owner's to create and none of them can be done from here.

There is one more assertion worth naming. A tag build checks that the tag agrees with project.godot's config/version, and fails if they differ. Two hand-maintained copies of one number is precisely the rot this repository keeps gate checks for elsewhere, and the copy that matters is the one baked into the build — not the one in the tag.

Still not published

Nothing has been uploaded, and that is not an oversight. The repository has no LICENSE file, and the music was generated under the owner's own subscription — public distribution, even free, even on itch, is a different question from personal use under most generators' terms. LF-206 has said so since the day it was filed, and it is the one item in it that engineering cannot close. The machinery is now entirely in place and idle behind a secret that does not exist yet, which is the correct place for it to be waiting.
