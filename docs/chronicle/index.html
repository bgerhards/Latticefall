    An arc is a dot product, and no angle ever enters the rules

    PLCdecision 078

    Free placement made which way an emplacement points a real question for the first time, so this is the rule written down before the three weapons that need it exist. An arc looks exactly like a job for the inverse tangent; it is not. A probe of 100,000 float64 pairs across CPython, Linux Godot and Windows Godot found seven operations whose results differ between the two C libraries — the worst of them on 4.32% of samples — and the owner plays the Windows build. So an arc is two dot products against a cosine authored in the data, with no angle, no trigonometry and no square root anywhere in either engine. No shipped weapon changed. The more interesting half is what that costs: the branch is gated on a key no shipped row carries, which is the acceptance criterion itself, so the 1,440-run parity gate executes the absent branch every time and proves nothing about the present one. A gate that runs the whole game says nothing about a branch the shipped data never enters — hence a new check, firing arcs agree, and three deliberate breaks to prove it can go red.
