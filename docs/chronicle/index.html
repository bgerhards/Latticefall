A documentary of how this game got made, written as it happens. Not a changelog — the plan, the measurements, the wins, and the things that went wrong along the way.

  • July 31, 2026

    It is the levels

    BALdecision 067

    The owner, playing: “the placement of most turrets are barely able to hit the enemies on the field.” Nothing in this project could see that — the sim only asks whether a build wins. sim/coverage.py (LF-176) is the instrument built to look, and it agrees with the owner: the median gun has a target in range about a third of the time, roughly one in five placed emplacements does essentially nothing, and the geometry says why — range values short relative to lane length on most anchors, slots simply too far from the lane on five Act 1 anchors. No range or slot was changed to get this answer.

    Behind infrastructure that did not exist

    PRCdecision 071

    rules parity — in the gate's own words the one thing making a balance claim in this project falsifiable — had never run in CI, not once. PRC-17 (#83) replaces the unreachable self-hosted nightly.yml with a container gate on every pull request — whose first real run went red, for the first genuine reason in this project's CI history rather than its own onboarding breakage, because the local verification behind it had quietly been measured against an already-imported tree.

    The stronger test was the one nobody ran

    PRC

    PRC-18's testing audit grepped every tracked scripts/*.gd filename against every tools/*.py, scripts/test/*.gd and data/scenarios/*.json file. Sixteen scripts came back with zero references, and gamepad input had no test in any form anywhere in the project — while two scenario files already on disk pinned real numbers to four decimal places and had simply never been wired into the gate. This entry closes gamepad, save/load, the recovery draft and audio loudness, and records the session's most expensive mistake along the way: a save-isolation flag that does not exist on this Godot build, silently ignored rather than rejected, that ran a tool twice against the real shared Linux dev save before an unchanged-mtime check caught it.

  • July 31, 2026

    Measuring the fifth non-negotiable, for the first time

    PRC

    CLAUDE.md's fifth non-negotiable — loudness-match audio, never peak-normalize — had never been measured by anything in the gate. The only audio check, check_sfx_reproducible, verifies determinism, not loudness; a synthesis change that reproduces byte-identical but drifts the whole bank's perceived level would have passed every check the project has ever run. PRC-18's testing audit found the gap. tools/audio/loudness.py closes it with a real ITU-R BS.1770-4 / EBU R128 gated integrated LUFS implementation, validated three independent ways and proved red on real assets before being trusted — and it ships with its own blind spot named rather than hidden.
